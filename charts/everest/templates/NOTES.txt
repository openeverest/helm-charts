Follow the steps below to get started:

RETRIEVE THE INITIAL ADMIN PASSWORD
====================================

Run the following command to fetch the initial admin password:

    kubectl get secret everest-accounts -n {{ .Release.Namespace }} -o jsonpath='{.data.users\.yaml}' | base64 --decode | yq '.admin.passwordHash'

**Note:** Passwords are currently stored in plaintext in this developer preview.
To update password replace <NEW_PASSWORD> with your desired password before running the command:

    kubectl get secret everest-accounts -n {{ .Release.Namespace }} -o yaml | \
      yq '.data."users.yaml" |= (@base64d | fromjson | .admin.passwordHash = "<NEW_PASSWORD>" | tojson | @base64)' | \
      kubectl apply -f -

ACCESS THE OPENEVEREST UI
==========================

To access the web UI, set up port-forwarding and visit {{ $pfUrl }} in your browser:

    {{ $pfCmd }}

INSTALL A PROVIDER TO MANAGE DATABASES
=======================================

OpenEverest v2 uses a modular architecture and does not bundle a database provider by default.
Browse the Hub to pick a provider and find its installation instructions:

    https://openeverest.io/extensions/

Providers can also be browsed and installed directly from the web UI.
